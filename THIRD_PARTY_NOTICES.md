# Third-party documentation

This project's code and original documentation are MIT licensed. Manufacturer
manuals retain their original Agilent/Keysight copyrights and are not covered by
that license. Their full text is not distributed in this repository or builds.

The manual catalog records original sources, editions and conversion hashes.
`scripts/fetch_manuals.py` retrieves references and converts them to Markdown for
local use. Generated manual files are ignored by Git. Users should observe the
terms applicable to those sources. Diagrams are not reproduced by the converter.

No implementation code was copied from the projects discussed in
`docs/comparison.md`. Dependencies retain their own licenses.
